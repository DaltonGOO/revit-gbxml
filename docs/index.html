Revit gbXML Exporter for HAP

A one-click Revit add-in that exports a clean gbXML file Carrier HAP can actually read — without the geometry headaches.

Download latest release View on GitHub

What it is

A free Revit add-in that exports your project's rooms, walls, floors, and openings to a gbXML file built for Carrier HAP energy analysis. Pick what you want to export, click a button, hand the file to HAP.

Works with:

Revit 2025 Revit 2026 Carrier HAP v6.2+

Why I made it

Revit's built-in gbXML export is finicky with HAP. Geometry comes through wrong, adjacencies don't line up, openings land in the wrong spot — and you end up cleaning things up by hand or dropping the whole approach.

I wanted a one-click solution for the common MEP workflow: open the model, run the export, get a file that imports into HAP without a fight. That's the whole goal — do one job, do it cleanly.

It's intentionally focused, not a full energy-modeling platform. If you need deep simulation tooling, there are bigger products out there. This is the tool I wished existed for the everyday Revit-to-HAP handoff.

How to install

  1. Download. Grab the latest release and unzip it. You'll have two files: RevitGbXmlExporter.dll and RevitGbXmlExporter.addin.
  2. Copy to your Revit add-ins folder. Press Win + R, paste the path for your Revit version, and drop both files in:
    Revit 2025 → %APPDATA%\Autodesk\Revit\Addins\2025
    Revit 2026 → %APPDATA%\Autodesk\Revit\Addins\2026
  3. Restart Revit. The exporter shows up on the Add-Ins tab.
First-time gotchas: If Windows blocks the DLL (it was downloaded from the internet), right-click RevitGbXmlExporter.dll → Properties → check Unblock → OK. On first launch Revit will warn about an unsigned add-in — choose Always Load.

How to use it

Open your Revit project, go to the Add-Ins tab, and run gbXML Exporter for HAP. Pick what to include, click Export, and a .xml file lands next to your project. Import that file into HAP.

Full documentation, including the linked-architectural-model workflow, lives in the README on GitHub.

Heads up: this is beta software. It works on the models I've tested, but always review the gbXML output and the resulting HAP loads before using them for design decisions. Provided as-is, MIT licensed. Found a bug? Open an issue.
